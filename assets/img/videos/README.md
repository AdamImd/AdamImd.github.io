# Video showcase posters

These JPEGs are midpoint frames extracted from the matching MP4s in `assets/video/projects/`. FFmpeg resized the frames to 960 pixels wide while preserving the aspect ratio. They serve as previews on `/videos/`; the recordings and their evidence captions remain the source of the demonstrated results.

- `g1-walking.jpg`, `g1-pickup.jpg`, `g1-hug.jpg`: Isaac Lab simulation replays. Pickup includes assistance, and enclosure is a near miss.
- `alem-coalitions.jpg`, `alem-comparison.jpg`: deterministic multi-agent simulation replays. The comparison does not establish an efficiency advantage.

The other showcase posters reuse existing project assets. Original media provenance is documented in `assets/img/projects/README.md` and the corresponding project pages.
